# Copa Esperança — Fighter Generator Seed v1

Descompacte este pacote na RAIZ do projeto.

Ele adiciona:
- `assets/participants/` — 30 fontes + face masters; Wendson/Wesley placeholders.
- `tools/fighter-generator/templates/` — os 8 sprites canônicos de pose, 576x576 RGBA.
- `tools/fighter-generator/prompts/` — prompts travados para master e frames.
- `tools/fighter-generator/participants.json` — roster e caminhos explícitos.
- `tools/fighter-generator/status.json` — máquina de estados inicial.
- `tools/fighter-generator/docs/` — regras que o Cursor deve respeitar.
- `tools/fighter-generator/src/` — vazio de propósito; o Cursor implementará aqui.
- `tools/fighter-generator/output/` — área de trabalho temporária.
- `tools/fighter-generator/review/` — contact sheets e relatórios de QA.

IMPORTANTE: este pacote NÃO gera imagens sozinho e NÃO altera o runtime do jogo.
